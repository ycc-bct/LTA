Design Direction

The big-picture visual system for the Road Maintenance Workflow Platform redesign — colour, typography and core components on one page. Screen layouts apply this system; details are tuned last.

SGDS-informed foundations (10-step scales, semantic colours) re-based to the LTA brand: teal primary, navy secondary, maroon for danger. Tokens live in tokens.css — change them there and every screen follows.

Layout

fixed topbar + sidebar · responsive grid

Sticky topbar 72px (logo · title · notifications · profile) over a 232px left sidebar. Content is a fluid card grid on a ~1220px max width, collapsing to a single column with a slide-in menu on tablet and phone. Spacing steps in multiples of 4; cards use radius 14px and the resting shadow.

Source: ycc-bct/LTA · tokens in tokens.css · applied on Overview, Operation dashboard and the work-instruction screens.
